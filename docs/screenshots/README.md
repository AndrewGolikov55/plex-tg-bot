# Screenshots

The two README files reference these PNGs. Drop your own captures with the matching filenames; the embedding markup at the top of `README.md` and `README.ru.md` will pick them up automatically.

| Filename | What to capture |
|---|---|
| `start-no-access.png` | `/start` reply for a brand-new user — greeting line + "Запросить доступ к Plex" button. |
| `request-flow.png` | The `/request` conversation: bot asking for email, user's email message, bot asking for the referrer. (One stitched screenshot or a vertically-cropped chat segment.) |
| `admin-panel.png` | `/admin` panel after pressing it in the admin chat — root menu `[👥 Users] [⏳ Pending] [🔄 Sync]`, OR the paginated users page (whichever shows the feature better). |

Recommended size: width 600-800px, PNG. Crop tightly — no Telegram chrome (status bar, contact list).
